# Demo assets

`coast-demo.png` is an original AI-generated sample image made with the built-in image generation tool for Fileel product screenshots and interaction testing. It contains no personal files or customer data. Product screenshots show the running app; the sample photograph does not represent a real destination.

## Image prompt

A quiet fictional coastal landscape with turquoise Atlantic water, warm limestone cliffs, a small sandy beach and wild grasses in soft morning sunlight. Realistic editorial landscape photography, wide 3:2 composition, natural texture, restrained color grading. No people, buildings, logos, text, UI or watermarks.

## Product video

`fileel-demo.mp4` is the original 12.5-second product recording supplied by the app creator. `fileel-demo.gif` is its looping, 960-pixel-wide, 15-fps preview with an optimized 128-color palette. The README embeds the GIF directly below the introduction artwork.

The original recording is retained here as the source for future previews.
