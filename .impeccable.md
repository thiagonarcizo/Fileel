## Design Context

### Users
Mac users converting and editing images, video, audio, PDFs, documents, spreadsheets, subtitles, and archives during everyday work

### Brand Personality
Elegant, discreet, precise — the creator selected a native premium direction with carefully defined forms; the creator then requested the macOS user-selected accent instead of a fixed brand color

### Aesthetic Direction
An original folded-ribbon mark, the current macOS control accent color, semantic macOS surfaces, New York display typography, and SF Pro interface text
Support light and dark appearances, increased contrast, reduced transparency, keyboard access, and reduced motion through system conventions
Tangerine is a functional reference only; no borrowed branding, illustrations, sounds, or code

### Design Principles
- Keep file content and the next action prominent
- Use native controls for predictable keyboard and accessibility behavior
- Reserve the accent for selection and primary actions
- Use the folded-ribbon geometry consistently in original identity assets
- Separate haptics from sound; sound is off by default
